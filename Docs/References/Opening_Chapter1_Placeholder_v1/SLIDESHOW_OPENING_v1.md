## 三张画如何接进游戏

总长约 20 秒：OP01 6 秒、OP02 7 秒、OP03 6 秒，之间约 0.4 秒交叉淡入。每张可前进，可跳过整段；字幕由 Unity 独立排版，图片中不生成文字。开场画只建立追赶动机，主线中的实际走、跑、跳和能力使用留给玩家。

### OP01 黄昏里的两个人

- **画面**：村庄外的草坡与石墙，暖金天空、蓝绿远丘、橄榄草地。妮芙在左，奥伊芯在右，正在轻松追逐或牵手转身；身体轮廓完整，动作不要遮住两张脸。手绘人物约占画面高度 30–40%，保留当前偏大的头身比。
- **故事作用**：先看懂她们是朋友，建立失去朋友前的温暖日常。
- **英文字幕草稿**：`At dusk, the hills were still a place to play.`
- **运动**：全幅缓慢推近 2%，不做角色肢体动画；关键面部避开下方约 18% 的字幕区。
- **输入**：按顺序附上 `MJ_ref/NIAMH_REF_v3.png`、`MJ_ref/OISIN_REF_v3.png`、`MJ_ref/S1_VILLAGE_KEY_03_pan_empty.png`。第三张可同时用于 Style Reference。白底角色参考的背景不进入成片。
- **必查**：头发与披风颜色各自正确；妮芙开场没有佩戴十字架——参考立绘上的十字架需要消失，因她此前已交给奥伊芯保管。若画出圣物，只能在奥伊芯处且不放大错误细节。

### OP02 奥伊芯听见召唤

- **画面**：同一片黄昏丘陵。奥伊芯在画面左中停下，望向右侧远处的古墓丘陵。远处只给小小的石门暗口与微弱冷光，不定死尚未完成的 S2 门体近景。妮芙可不入画，避免视线关系混乱。
- **故事作用**：她听见妮芙没有听见的声音；召唤带来好奇和失神，而非怪物恐吓。古墓自行开启的线索以远景表达。
- **英文字幕草稿**：`Then Oisín heard something Niamh could not.`
- **运动和声音**：轻推向她的视线方向；音乐减薄，低语是后续音频制作项，本轮无配音成品。
- **输入**：`MJ_ref/OISIN_REF_v3.png` 与 `MJ_ref/S1_VILLAGE_KEY_03_pan_empty.png`。保持 OP01 的光线、线条和颜色；选出 OP01 后，可替换环境参考为它以延续画面风格。
- **必查**：不出现守门贵族、普卡或女王；不新增清晰欧甘字；发型、花冠与钟袖仍按奥伊芯 v3。

### OP03 她跑向树林

- **画面**：奥伊芯在右前方跑向村庄外的树影；妮芙在左后方转身追赶。左侧仍为暖村庄，右侧树影偏冷；两人朝右，与游戏的前进方向一致。不要把两人直接画在古墓门内。
- **故事作用**：建立追踪路线，衔接 S1 的玩家操作。奥伊芯进入古墓的近景留到森林后、S2 前的后续过渡，避免“已到墓门又退回村庄”的空间跳跃。
- **英文字幕草稿**：`Oisín ran towards the trees. Niamh followed.`
- **衔接**：画面淡暗后显示 S1 村庄的真实出生点并交还控制；若使用章节名，`CHAPTER I` / `THE THRESHOLD` 仅作待定英文标题，须与最终章节命名一致，不烘焙入图。
- **输入**：两位角色 v3 + 村庄环境参考；`TechnicalArt/mock/FOREST_LIGHTING_TARGET_warm.jpg` 仅供人工判断后续暗场的冷暖方向，不把整张暗森林上传替代村庄风格参考。
- **必查**：同一角色前后不换衣、不换头身比；前进方向一致；妮芙仍无十字架；树林只是画面边缘的目的地，不能造成已进入森林再回村庄的错觉。

## MJ 执行与文件记录

完整 prompt 是 `MJ_ref/Slideshow/Opening_v1/OP01_prompt.txt` 至 `OP03_prompt.txt`。参考用途、文件散列、预期参数与空的生成记录在同目录 `generation_manifest.json`。

按 2026-11-14 核对的官方说明，当前 V8.2 Edit 模型可接多张角色/环境参考，且可与 Style Reference 组合。本批拟使用 V8.2 Edit，附图后执行 prompt 内的 `--ar 16:9 --raw`；正式提交前以网页实际设置核对，记录版本，不混用旧 Niji 6 的 `--cw`。若当前界面不提供此模型，先更新执行记录再更换方案，不能声称已按该模型出图。

先只生成 OP01 一组候选，挑中风格后再做 OP02/03；避免三张各自选成不同风格。首轮不加个人化参数或随机风格代码。多人物错配时先局部修订一个角色，再复核另一位；不以整图反复重抽替代一致性检查。

每次记录：实际完整 prompt、模型/模式、参数、参考用途、生成日期、job 链接或 ID、下载原图、选中编号及理由。原图候选保存在 `MJ_ref/Slideshow/Opening_v1/`；人工修订源文件与最终 1920×1080 PNG 通过后才放入 `TechArtAsset/Storyboards/Opening_v1/`。未经验证的放大图不标记为定稿。

## 选图与游戏内验收

- 对照村庄实机：黄昏金色天空、蓝绿色阴影、深色线条、简化层次；不要只保留“水彩”而丢掉实机场景的轮廓力度。
- 人物：发色、眼色、衣装、头身比与各自参考一致；无额外人物/重复肢体/夸张真实皮肤，无角色饰物互换。
- 故事连续：圣物在奥伊芯处、妮芙追赶方向向右，远处门没有剧透角色身份。
- 画幅：16:9，字幕安全区，轻微推拉后角色仍完整；图片无字、边框、签名和界面元素。
- 将 OP03 与 S1 的实际画面相邻播放再评估风格落差。字幕用项目指定 IM Fell English，字号和跳过按钮在游戏内验证。
